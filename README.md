# ⋆｡‧˚ʚ🔐ɞ˚‧｡⋆ Análise de Vulnerabilidades em Código Gerado por IA

Projeto voltado à **análise de vulnerabilidades de segurança em códigos-fonte produzidos por ferramentas de Inteligência Artificial**.

A proposta é desenvolver uma ferramenta em Python capaz de analisar códigos gerados por IA, identificar possíveis vulnerabilidades de segurança e apresentar os resultados de forma estruturada.

🚧 **Este projeto está em fase inicial de desenvolvimento.** As funcionalidades serão implementadas e aprimoradas ao longo da pesquisa.

---

# ⋆˙⟡🔎⋆˙⟡ Objetivo

O objetivo do projeto é investigar a presença de vulnerabilidades de segurança em códigos produzidos por ferramentas de Inteligência Artificial e desenvolver mecanismos automatizados para sua identificação.

A ferramenta será desenvolvida em **Python** e utilizará técnicas de análise estática de código para identificar padrões potencialmente vulneráveis.

---

# ⭒₊ ⊹🧪 Metodologia

O projeto será desenvolvido em etapas:

1. 📚 Estudo de vulnerabilidades de segurança em código-fonte
2. 🐍 Desenvolvimento do analisador em Python
3. 🌳 Análise da estrutura sintática dos códigos
4. 🔎 Implementação de regras para identificação de vulnerabilidades
5. 🤖 Coleta de códigos produzidos por ferramentas de IA
6. 📊 Análise e classificação dos resultados
7. 📈 Avaliação da eficácia da ferramenta desenvolvida

---

# ⋆.˚✮🔐✮˚.⋆ Vulnerabilidades Investigadas

A ferramenta será desenvolvida gradualmente para identificar diferentes categorias de vulnerabilidades, como:

- 🔴 SQL Injection
- 🔴 Command Injection
- 🟠 Code Injection
- 🟠 Cross-Site Scripting (XSS)
- 🟡 Exposição de informações sensíveis
- 🟡 Uso inadequado de funções de segurança
- 🟡 Armazenamento inseguro de credenciais

> ⚠️ As categorias acima representam o escopo planejado do projeto e não significam que todas já estejam implementadas.

# ⭒₊ ⊹💻 Primeira Versão

A primeira versão do projeto tem como objetivo estabelecer a estrutura inicial do analisador.

Atualmente, o projeto está sendo desenvolvido para:

📂 receber arquivos de código Python;

📖 realizar a leitura do código;

🌳 transformar o código em uma estrutura AST;

🔎 preparar a análise automatizada de possíveis vulnerabilidades.

# ⋆｡‧˚ʚ📊ɞ˚‧｡⋆ Resultados Esperados

Espera-se desenvolver uma ferramenta capaz de:

identificar possíveis vulnerabilidades em código gerado por IA;

classificar os problemas encontrados;

indicar a localização das vulnerabilidades no código;

fornecer informações sobre os riscos identificados;

gerar dados que possam ser utilizados na análise científica dos resultados.

# ₊˚ ☁️⋅♡🧪 Pesquisa

Este projeto está sendo desenvolvido como parte de uma proposta de iniciação científica, com foco na interseção entre:

Inteligência Artificial + Desenvolvimento de Software + Cibersegurança

A pesquisa busca contribuir para a discussão sobre a segurança de códigos produzidos por ferramentas de IA e sobre a utilização de métodos automatizados para sua análise.
